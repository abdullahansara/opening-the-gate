# Decision log

Assumptions, unresolved choices and deviations, in the order they were made. "Pilot" = `results/pilot`
(validation seeds 1000+). The frozen full run uses held-out seeds 10000+, which were never used before it.

| ID | Decision | Reason / status |
|----|----------|-----------------|
| D-01 | Task world = compositional regression over a 46-term grammar (const, linear, square, pairwise product, sign gate, gate x variable), d=5, T=160. | Spec 3 recommended symbolic regression; enumerable hypothesis space lets "structure" be scored exactly. |
| D-02 | Hypotheses are linear in selected grammar terms; inference is penalised least squares with BIC-style score and a mixture over <= m held hypotheses, not full SMC/MCMC. | Explicit, tractable approximation (docs/model_specification.md). It is **not** a full Bayesian posterior; deviation from spec 4's preferred methods, acknowledged. |
| D-03 | Gating g acts on *surprising* observations only (|z|>2), via a pre-drawn uniform per trial so that every compared condition faces identical random numbers. | Anti-confound (spec 4): g never changes proposal budget, search breadth or window size. Tested in `test_gating_does_not_set_proposal_budget`. |
| D-04 | Proposal budget per revision B = 14 f likelihood evaluations; workspace operations and external reads/writes are charged against B. A `free_artifact_ops` ablation reports the ecologically unequal case. | Matched-budget primary analysis plus unequal-budget analysis (spec 4, 5). |
| D-05 | Sampled design (Sobol over g,f,c,pi,m x 4 artifact conditions x 4 environments, paired worlds) instead of a full factorial grid. | Spec 6 allows a statistically justified fractional design; chosen for speed (user request for a quicker run). |
| D-06 | Four artifact conditions: internal (window W=12m), internal_big (matched capacity, 200), passive store, interactive workspace. | `internal_big` is the matched-memory control; `passive` is the ablation that keeps storage but disables manipulation. |
| D-07 | **Post-pilot revision of the H5 decision rule.** Original rule: curvature negative in >= 95% of bootstraps AND no significantly negative quadratic term in admitted-observation count vs g. Revised: curvature rule AND the admitted-count means are monotone non-decreasing across g bins (2% tolerance). | In the pilot the admitted count was *concave* (saturating) in g but monotone; concavity is not non-monotonicity, so the original rule was mis-specified. Both verdicts are reported (`H5.supported_original_rule`, `H5.supported`). Revision made after seeing pilot data, before the full run. |
| D-08 | **Post-pilot correction of artifact cost units** (annotate 0.002->0.008, compare 0.001->0.005, combine 0.1->0.05 per unit) after `scripts/bench_costs.py` measured workspace ops at ~2.0-2.5 likelihood-evaluation equivalents versus 0.55 units configured. | Costs must reflect measured compute, not guesses. Pilot was re-run with corrected costs; the provisional run is kept as `results/pilot_v1_provisional_costs`. The change is independent of which outcomes it favours. |
| D-09 | `ll_gap` (held-out log-likelihood gap to oracle) has extreme outliers (overconfident predictive variance after overfitting). Primary usefulness is R^2 against the true noiseless function on held-out inputs; ll_gap is reported as median and mean, plus 90% interval coverage. | Overconfidence is a genuine agent property, kept visible rather than clipped away. |
| D-10 | Number of worlds per environment W=48 and 128 design points, from `scripts/power.py` on the pilot (rule: 95% CI half-width <= 0.02 on the paired artifact difference and <= 0.05 on the interaction slope). | Pre-specified rule; W=48 was the smallest grid value meeting both. |
| D-11 | Not implemented: separate spurious-correlation environment; mixed-model random effects crossed with design point; Docker image; real CI service. | Time/scope. Spurious structure is represented only by irrelevant inputs, outliers and rule shifts. CI is replaced by a local fresh-environment run (see audit). |
| D-12 | Held-out seeds were not touched before the frozen run. Full config hash and source hash recorded in `results/full/manifest.json`. Frozen config hash: `da6c43d2560be9113be59dc95794c1c6d2267ea0dfdfdf112fac6019f84ab6a6`; source hash: `879b2612329ce33be074e6b71cf5615d4f8619f77d9a0d93feeddd3b9f7340b9`. | Freeze before running (spec 12.6). |

## Known limitations

- Linear-in-terms models mean "structural discovery" is term selection, not open-ended program induction.
- The agent's inferential approximation is simple; results characterise this mechanism, not Bayesian inference in general.
- No psychological construct is identified with any agent parameter (spec 1).
